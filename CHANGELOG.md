## [Unreleased]

### Added

- `vcs zone suggest --assist <cmd>` (and the user-only `zone.assist` setting, `--no-assist`, `--assist-timeout`): an
  opt-in external assistant proposes zone boundaries. Directory paths, manifest paths and CODEOWNERS rules (no file
  contents) are sent; `vcs` validates every proposal and prints it next to the heuristic ones with a `source` label.
  Proposals only, nothing is applied. New `"kind":"zone-suggest"` request kind of the assistant protocol; the merge
  request is unchanged. `vcs-assist-claude` and `vcs-assist-openai` handle it. First version, mock-tested, not yet
  called against a live API. See docs/zone-assist.md.
- `vcs zone apply --dir <path> --name <name>` adopts an explicit directory (for a path only the assistant proposed).
- `--json` of `zone suggest`: `zones[]` entries carry `"source":"heuristic"`.

## [0.1.0] - 2026-11-08

First tagged release. Early research software; see the README for status and limitations.

### Added

- Version control system written from scratch in Rust with no git, libgit2 or Perforce underneath:
  own object format (BLAKE3, strict canonical codec), packs, index and wire protocol.
- Zones: independent histories per path prefix inside one global, deduplicated object graph, with
  atomic multi-zone publishes.
- Zone ontology for agents (`vcs zone describe/graph/explain/changes --json`) and usage-profile based
  zone selection for `clone`/`sync --auto`.
- S3 as the only authority through a compare-and-swap manifest, with server-side group commit
  (`vcs-server`) and an executable protocol model checked over crashes and interleavings.
- Stable change ids kept across `rebase`, an operation log (`vcs op log/undo/restore`), and
  first-class conflicts (`vcs conflict`, `vcs resolve`).
- Lease locks in the manifest with fencing, enforced when publishing through `vcs-server`.
- Built-in large-file engine using content-defined chunking, with streaming add and checkout.
- Pack format v2 (zstd per object); v3 (sketch-ordered deltas) as an opt-in for transfers.
- Lazy tag table for fast `log` and similar commands on repositories with many tags.
- Import from git and Perforce, and git interop; CLI reference generated by
  `scripts/gen_cli_reference.sh`.
- Dual license: `MIT OR Apache-2.0`.

### Known limits

See [docs/known-limits.md](docs/known-limits.md) for measured scale limits (10M-file `status`,
`gc`/`fsck` memory at 1M commits, opt-in `refs-delta` layout, opt-in sharded manifest).
